* Archives

| Key            | Action                                                 |
|----------------+--------------------------------------------------------|
| =Enter= on =.rar= | extract with =unar= (custom opener)                 |
| =Enter= on zip/7z/tar... | extract with built-in =extract= plugin (=7zz=) |
| =O=            | pick "Extract here" explicitly                         |

- Split RARs (=.rar= + =.r00=, =.r01= ...): hover the =.rar=, the rest is found
  automatically.
- Homebrew's =7zz= / =7z= ship *without* the RAR codec: lists fine, extracting fails
  with =Unsupported Method= and leaves a 0-byte file. Hence the =unar= opener.
- Single-file archives extract straight into the current dir (no subfolder).

** Task manager

Status bar "=N left=" = N tasks still queued/running (copy, extract, ...). No
"done" message on success -- the counter disappears; errors pop up.

| Key            | Action                      |
|----------------+-----------------------------|
| =w=            | open task manager           |
| =j= / =k=      | move between tasks          |
| =Enter=        | inspect task output         |
| =x=            | cancel task                 |
| =w= / =Esc=    | close                       |

* Config gotchas (Yazi 26)

- Opener placeholders: =%s= (all selected, auto-quoted) and =%s1= (first file).
  The old shell style ="$@"= / ="$1"= expands to nothing -> "Process exited with
  exit code 1".
- Open rules match with =url = "*.rar"= -- the old =name= key fails with
  "at least one of `url` or `mime` must be specified".
- Config isn't reloaded live: quit and restart after editing.

Example (=yazi.toml=, the =unar= opener used above):

#+begin_src toml
[opener]
unar = [{ run = 'unar -f %s1', desc = "Extract (unar)", block = true }]

[open]
prepend_rules = [{ url = "*.rar", use = ["unar", "reveal"] }]
#+end_src
