* Editing

Navigation and editing use evil (Vim) keys.

| Key     | Action                        |
|---------+-------------------------------|
| S-Mouse | Select text in terminal mode  |

Redo with ~C-r~ requires ~(setq evil-undo-system 'undo-redo)~ before ~(evil-mode 1)~.

* Window Management
# Emacs terminology: Frame = OS window, Window = split pane, Buffer = file/content

** Frames (OS windows)

| Key     | Action                |
|---------+-----------------------|
| C-x 5 2 | Create a new frame    |
| C-x 5 0 | Close current frame   |
| C-x 5 o | Switch to next frame  |

** Windows (split panes)

| Key   | Action                                 |
|-------+----------------------------------------|
| C-x 2 | Split window horizontally (top/bottom) |
| C-x 3 | Split window vertically (left/right)   |
| C-x 0 | Close current window                   |
| C-x 1 | Close all other windows (maximise)     |
| C-x o | Switch to next window                  |

** Buffers

| Key     | Action                               |
|---------+--------------------------------------|
| C-x C-f | Open / create a new file in a buffer |
| C-x b   | Switch to a buffer (prompts by name) |
| C-x C-b | List all open buffers                |
| C-x k   | Kill (close) current buffer          |

** Bookmarks

| Key     | Action                        |
|---------+-------------------------------|
| C-x r m | Set bookmark for current file |
| C-x r b | Jump to a bookmark            |
| C-x r l | List all bookmarks            |
| C-x r d | Delete a bookmark             |

* Org Mode

** Structure templates (type then ~Tab~ to expand)

| Shortcut | Expands to                            |
|----------+---------------------------------------|
| <s       | #+BEGIN_SRC ... #+END_SRC             |
| C-c '    | Edit source block in dedicated buffer |
| <e       | #+BEGIN_EXAMPLE ... #+END_EXAMPLE     |
| <q       | #+BEGIN_QUOTE ... #+END_QUOTE         |
| <c       | #+BEGIN_CENTER ... #+END_CENTER       |
| <l       | #+BEGIN_EXPORT latex ... #+END_EXPORT |
| <h       | #+BEGIN_EXPORT html ... #+END_EXPORT  |
| <a       | #+BEGIN_EXPORT ascii ... #+END_EXPORT |
| <c       | #+BEGIN_COMMENT ... #+END_COMMENT     |

Note: requires ~(require 'org-tempo)` in config in Emacs 26+.

** yasnippet - Parameterized tempaltes

| Shortcut           | Action                                                  |
|--------------------+---------------------------------------------------------|
| M-x yas-reload-all | Ensures snippets in ~~/.emacs.d/snippets~ are picked up |
| imgcap             | Insert image caption (custom)                           |

The default directory ~yasnippet~ is ~~/emacs.d/snippets/~ organized by mode name:
#+begin_example
  ~/.emacs.d/snippets/
  ├── org-mode/
  │   └── imgcap
  ├── python-mode/
  │   └── def
  └── js-mode/
      └── cl
#+end_example

** Todo & Agenda

| Key         | Action                                  |
|-------------+-----------------------------------------|
| C-c C-t     | Cycle TODO state (TODO -> DONE -> none) |
| C-c C-d     | Set a deadline                          |
| C-c C-s     | Set a schedule date                     |
| C-c C-x C-i | Clock in (start timing a task)          |
| C-c C-x C-o | Clock out                               |
| C-c a       | Open the agenda dispatcher              |

*** Agenda filters

Open the global TODO list with ~C-c a t~, then use:

- ~/~: Filter entries, e.g. ~+bitshift~ to show only that tag or ~-paper~ to exclude it. Confirm with ~RET~.
- ~|~: Remove all filters and show the full list again.

* Dired (File Manager)

** Opening & Closing

| Key     | Action                             |
|---------+------------------------------------|
| C-x d   | Open Dired (prompts for directory) |
| C-x C-f | Open Dired (prompts for file)      |
| C-x C-j | Jump to Dired in current directory |
| q       | Close Dired buffer                 |

** File Operations

| Key       | Action                                              |
|-----------+-----------------------------------------------------|
| +         | Create a new directory                              |
| C-x C-f   | Create a new file (open for editing)                |
| m         | Mark a file (~*~)                                   |
| t         | Toggle mark (invert selection)                      |
| u         | Unmark a file                                       |
| U         | Unmark all files                                    |
| d         | Flag file for deletion (~D~)                        |
| x         | Delete files flagged with ~d~                       |
| D         | Delete marked (~*~) files, or file at cursor        |
| C         | Copy marked file(s)                                 |
| R         | Rename / move a file                                |
| % m REGEX | Mark files matching a regex pattern                 |
| g r       | Refresh Dired buffer                                |
| g x       | Runs ~browse-url-of-file~ and opens file in browser |

~x~ only acts on ~d~ flags. If it says /No deletion requested/, the files are marked with ~m~, so use ~D~ instead.

*** Delete everything except one file

~U~ (clear marks) → ~t~ (mark all) → move to the file to keep → ~u~ → ~D~ → confirm

* Python & Compilation

| Key / Command | Action                                     |
|---------------+--------------------------------------------|
| M-x compile   | Run a shell command, e.g. ~python3 foo.py~ |
| M-x recompile | Rerun last compile command                 |
| C-c C-p       | Start Python REPL                          |
| C-c C-c       | Send Python buffer to REPL                 |
| C-c C-r       | Send selected region to REPL               |

Bind ~F5~ to recompile and enable ANSI colors in compilation output (~init.el~):
#+begin_src emacs-lisp
(global-set-key (kbd "<f5>") #'recompile)

(require 'ansi-color)
(add-hook 'compilation-filter-hook #'ansi-color-compilation-filter)
#+end_src
